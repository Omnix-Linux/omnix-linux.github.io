Link swarm materialization

Omarchy, ported to Omnix as Autarchy.

Omnix provides the standard Linux paths Autarchy and other apps expect, with NixOS packages, reproducible configuration, and system rollbacks underneath.

A swarm of links connects those familiar paths to packages in /nix/store. This FHS-compatible layout upgrades and rolls back with your system.

Familiar paths. Nix underneath.

FHS paths + Nix packages

  • /bin/bash -> /nix/store/…-bash/bin/bash // shell
  • /usr/bin/* -> $PATH // tools & interpreters
  • /lib, /usr/lib -> /nix/store/…/lib // libraries
  • /lib64/ld-linux-x86-64.so.2 -> nix-ld // ELF loader
Autarchy

Omarchy, ported to Omnix.

Autarchy brings Omarchy's desktop to Omnix. The port carries over its Hyprland configuration, keybindings, themes, and scripts to preserve the experience.

Choose stable for a pinned Omarchy release or latest to follow its development branch. Desktop upgrades and rollbacks follow your system configuration.

sourceOmarchy's own repo, pinned: stable is v4.0.4, latest tracks its development branch
scriptsOmarchy's commands, themes, and defaults installed read-only at $OMARCHY_PATH, where its config looks for them
configEach user's ~/.config seeded once from Omarchy's templates, the way its installer does it
packages131 of Omarchy's 147 base packages mapped to nixpkgs, all downloaded prebuilt
desktopHyprland running Omarchy's Lua config unmodified, tested in a VM on every change
updatespacman replaced by nix flake update and a rebuild, with rollback
1 of 4 Why Omnix

cache.nixos.org for the same fast packages.

Omnix adds the standard Linux layout on top of NixOS: a loader at /lib64, a declared set of common libraries in /usr/lib, a fresh ld.so.cache, and a /bin that resolves #!/bin/bash. Manylinux wheels, rustup, vendor SDKs, Electron apps, and Playwright browsers start without patching or wrappers.

omnix

$ python3 -c 'import ctypes.util as u; print(u.find_library("z"))'
libz.so.1

$ head -1 ./install.sh && ./install.sh

2 of 4 Why Omnix

Prebuilt when available. Compiled when needed.

The rule is add, never relocate. Omnix never patches or moves a nixpkgs package, so Omnix can use the same prebuilt packages as NixOS from cache.nixos.org. Installs and upgrades download those packages when available and compile when necessary.

3 of 4 Why Omnix

Pick your desktop at install time.

The base stays small. Everything opinionated lives in a flavor, a complete system in its own repository. Autarchy ports Omarchy's keyboard-driven Hyprland desktop. Atrium is a polished, mouse-first KDE Plasma desktop with independent virtual desktops on every monitor.

The installer reads the flavor list live, so new styles show up without a new ISO.

4 of 4 Why Omnix

Your system. Your rollback.

Your system is a flake that you own in /etc/nixos, and your flavor is one input in it. Switch from Atrium to Autarchy by changing that input and rebuilding.

The FHS layer is generated from your configuration and versioned with it, so rolling back a generation rolls back the library layout too. The previous system is always one entry away in the boot menu.
