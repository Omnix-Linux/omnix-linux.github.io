# Desktop preview icons

The preview launcher order follows `dockLaunchers` in the user's `nixos/system/configuration.nix`, including its Hermes launcher. The Desktops control follows `grid-view.desktop` beside the per-monitor pager.

These application and Breeze icons were copied from the installed desktop icon themes. They identify their respective applications; ownership remains with their original projects. Zoom, Photon Studio, and Docker VM use text initials because their icons were unavailable in the installed theme.

This is an illustrative website preview. Launchers show an application label; they do not start applications. The clock opens a calendar, and Desktops opens workspace thumbnails for two monitors.

The Apps catalog also uses Alacritty, Chromium, Firefox, Ghostty, Chrome, WezTerm, Discord, Element and Thunderbird icons from the pinned nixpkgs packages (revision `c59305bab2065cfecc4944690d9eedbb56f3a9fa`). Helium’s icon comes from its upstream 0.18.3.1 Linux archive. Application names and logos belong to their respective projects.

Office catalog icons (except Calligra and Thunderbird) are unmodified SVGs from [Papirus](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme/tree/bf539287ef5dc18529424a02cccee76175920a6f), licensed under GPL-3.0 (see [license](PAPIRUS-LICENSE)). Calligra uses the installed Breeze Words icon; Thunderbird retains its existing package icon. Logos identify their respective applications.
